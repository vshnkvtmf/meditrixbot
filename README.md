# 🏰 Kingdom Bot — Discord-бот (средневековье)

Python + discord.py + SQLite. Команда `/setup` разворачивает весь сервер: категории, каналы, роли, форумы с тегами, красивые «Правила» и «Шпаргалку».

## Возможности
- `/setup` — создаёт структуру, роли (🏆 Готовится к запуску / 👑 Владелец / 👨‍💻 Модератор), порядок ролей, выдаёт роль всем и Владельца вам (повторный запуск безопасен, обновляет правила/шпаргалку)
- Приветствие в ЛС при входе + автовыдача роли
- «🛠 Создать войс»: личная комната с ником участника + панель управления в ЛС (название, лимит, закрыть, скрыть, выгнать, удалить); пустые комнаты удаляются
- Репутация: 👍❤️🔥⭐ = +1, 👎😡 = −1 (свои реакции не считаются), `/tab` — топ, `/profile`, `/daily`
- Мини-ивенты в 15:00, 17:00, 20:00 во временной категории (счёт, анаграмма, угадай число), победитель получает +3 репутации
- Форумы: теги, закреплённый гайд, `/solved` в техподдержке, авто 👍/👎 на идеях

## Настройка
1. https://discord.com/developers/applications → New Application → Bot → скопируйте токен.
2. В Bot включите **Server Members Intent** и **Message Content Intent**.
3. Пригласите бота (OAuth2 → URL Generator: scopes `bot` + `applications.commands`, право **Administrator**).
4. На сервере включите **Community** (нужно для форумов: Настройки → Включить сообщество).
5. Роль бота перетащите **на самый верх** списка ролей.
6. `cp .env.example .env`, впишите токен → `pip install -r requirements.txt` → `python bot.py`
7. В Discord введите `/setup`.
